Installable pack for the pi coding agent. Extensions include a second-model
review (`/oracle`), OSC52 clipboard copy and a git-backed wiki. Skills cover
research against primary sources, security audits, OSM and Paperless lookups
and cross-model review loops. Prompts handle atomic commits and publishing. Install it with `pi install`, or with the Home Manager module
on Nix, which also pulls in the CLI tools the resources need.
